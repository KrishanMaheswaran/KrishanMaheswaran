## Featured Projects

### 01. WayPoint — Fleet Telemetry Platform

**C++17 · Python · FastAPI · PostgreSQL · Docker · CMake**

[View Repository](https://github.com/KrishanMaheswaran/waypoint)

WayPoint is a multi-component fleet telemetry platform
that connects a C++17 vehicle simulator with a Python
backend for telemetry ingestion, validation, persistence,
and retrieval.

**Engineering highlights:**

- Developed a C++17 simulator generating telemetry
  for five virtual vehicles over HTTP.
- Built a FastAPI backend with PostgreSQL persistence
  using SQLAlchemy and Alembic migrations.
- Implemented idempotent telemetry ingestion to
  prevent duplicate event storage.
- Added bounded retries to handle temporary
  service unavailability.
- Created automated Python and C++ tests
  to validate backend and simulator behavior.
- Added reproducible local benchmarks for
  measuring telemetry ingestion performance.

**Key engineering focus:** Reliability, service
communication, API design, testing, and performance.
